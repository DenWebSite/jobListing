# Vue Jobs — Доска объявлений о вакансиях
Пет-Проекту 8 месяцев, но выложил на GitHub только сейчас, к сожалению. Приятного ознакомления!

Одностраничное приложени (SPA) для публикации, просмотра, редактирования и удаления вакансий. Пользователь может посмотреть список вакансий, открыть карточку с деталями, добавить новую вакансию через форму, отредактировать или удалить существующую.

## Стек технологий

| Категория | Технология |
|---|---|
| Framework | Vue 3 (Composition API, `<script setup>`) |
| Сборщик | Vite 7 |
| Роутинг | vue-router 4 |
| HTTP-клиент | axios |
| Стилизация | Tailwind CSS 3 + PostCSS/Autoprefixer |
| Иконки | PrimeIcons |
| Уведомления | vue-toastification (toast-сообщения) |
| Индикатор загрузки | vue-spinner (`PulseLoader`) |
| Mock-бэкенд | json-server (эмулирует REST API поверх `jobs.json`) |
| Dev-инструменты | vite-plugin-vue-devtools |

Проект использует **Composition API** во всех компонентах (`<script setup>`), реактивность через `ref`/`reactive`, `computed`-свойства и хуки жизненного цикла (`onMounted`).

## Функциональность

1. **Главная страница (Home)**
   - Hero-секция с заголовком и подзаголовком.
   - Блок из двух карточек: "Для разработчиков" (ссылка на список вакансий) и "Для работодателей" (ссылка на форму добавления вакансии).
   - Превью первых 3 вакансий с кнопкой "View All Jobs".

2. **Список вакансий (Jobs)**
   - Загрузка всех вакансий с бэкенда через axios.
   - Отображение сеткой (grid), адаптивной под мобильные/десктоп.
   - Спиннер (`PulseLoader`) на время загрузки данных.
   - Раскрытие/сворачивание полного описания вакансии по клику на "More/Less" (описание обрезается до 90 символов).

3. **Карточка вакансии (Job Details)**
   - Полная информация: тип занятости, заголовок, локация, описание, зарплата.
   - Блок с информацией о компании: название, описание, контактный email и телефон.
   - Кнопки управления: **Edit Job** (переход к форме редактирования) и **Delete Job** (удаление с подтверждением через `window.confirm`).
   - Toast-уведомление об успехе/ошибке при удалении.

4. **Добавление вакансии (Add Job)**
   - Форма с валидацией обязательных полей (`required`).
   - Поля: тип занятости (select), название вакансии, описание (textarea), зарплата (select с диапазонами от "Under $50K" до "Over $200K"), локация, а также блок данных о компании (название, описание, email, телефон).
   - Отправка `POST`-запроса на бэкенд, редирект на страницу созданной вакансии, toast об успехе/ошибке.

5. **Редактирование вакансии (Edit Job)**
   - Та же форма, что и Add Job, но предзаполненная текущими данными вакансии (подгружаются по `id` из URL).
   - Отправка `PUT`-запроса, редирект на страницу вакансии, toast-уведомление.

6. **Навигация (Navbar)**
   - Логотип + название "Vue Jobs", ссылки на Home / Jobs / Add Job.
   - Подсветка активного пункта меню (`isActiveLink`, `exact-active-class`).

7. **Страница 404**
   - Отдельный компонент для несуществующих маршрутов с иконкой предупреждения и ссылкой на главную.

## Маршрутизация

Роуты объявлены в `src/router/index.js` с использованием `createWebHistory`:

| Путь | Имя | Компонент | Описание |
|---|---|---|---|
| `/` | `home` | `HomeView` | Главная страница |
| `/jobs` | `jobs` | `JobListings` | Список всех вакансий |
| `/jobs/:id` | `job` | `JobView` | Детали конкретной вакансии |
| `/jobs/add` | `add-job` | `AddJob` | Форма создания вакансии |
| `/jobs/edit/:id` | `edit-job` | `EditJobView` | Форма редактирования вакансии |
| `/:catchAll(.*)` | `not-found` | `NotFoundView` | 404 для любых нераспознанных путей |

## Работа с данными (API)

Реального backend-сервера в проекте нет — вместо него используется **json-server**, который поднимает REST API поверх файла `src/jobs.json` (5 демо-вакансий с полями `title`, `type`, `location`, `description`, `salary`, `company`).

- Скрипт `npm run server` запускает `json-server --watch src/jobs.json --port 5000`.
- В `vite.config.js` настроен **прокси**: все запросы фронтенда на `/api/*` перенаправляются на `http://localhost:5000/*` (префикс `/api` обрезается).
- Используемые запросы (через `axios`):
  - `GET /api/jobs` — список вакансий (`JobListings.vue`);
  - `GET /api/jobs/:id` — одна вакансия (`JobView.vue`, `EditJobView.vue`);
  - `POST /api/jobs` — создание вакансии (`AddJob.vue`);
  - `PUT /api/jobs/:id` — обновление вакансии (`EditJobView.vue`);
  - `DELETE /api/jobs/:id` — удаление вакансии (`JobView.vue`).

Для работы приложения **нужно параллельно запускать и Vite dev-сервер, и json-server**

## Компоненты

- **`Card.vue`** — переиспользуемая обёртка с настраиваемым фоном (`bg` prop) и `<slot>` для контента; используется в `HomeCards.vue`.
- **`Hero.vue`** — простой презентационный компонент, принимает `title` и `subtitlle` (опечатка в названии prop сохранена из исходного кода).
- **`JobListing.vue`** — карточка вакансии с локальным состоянием `showFullDescr` и `computed`-свойством `truncatedDescr` для обрезки длинного описания.
- **`JobListings.vue`** — контейнер, который сам загружает данные (`onMounted` + `axios.get`), управляет состоянием загрузки (`reactive` объект `state`) и рендерит список `JobListing`; принимает `limit` (сколько вакансий показать) и `showButton` (показывать ли кнопку "View All Jobs") в качестве props.
- **`BackButton.vue`** — статическая ссылка "Back to Job Listings" с иконкой.
- **`Navbar.vue`** — определяет активную ссылку через `useRoute()` и подсвечивает её отдельным классом.

## Установка и запуск

### Требования
- Node.js `^20.19.0` или `>=22.12.0` (см. `engines` в `package.json`)

### Шаги

```bash
# 1. Установить зависимости
npm install

# 2. Запустить mock-бэкенд (json-server) — в отдельном терминале
npm run server
# поднимется на http://localhost:5000

# 3. Запустить dev-сервер Vite — в другом терминале
npm run dev
# приложение будет доступно на http://localhost:5173 (по умолчанию)
```

Запросы с фронтенда на `/api/**` автоматически проксируются на json-server благодаря настройке в `vite.config.js`.
